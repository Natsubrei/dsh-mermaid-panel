# Security

Report a vulnerability in this plugin in private.

Use [GitHub private vulnerability reporting](https://github.com/Natsubrei/dsh-mermaid-panel/security/advisories/new), or email [natsunobourei@163.com](mailto:natsunobourei@163.com).

Do not open a public issue that contains a working exploit.

The page renders Mermaid source taken from the conversation already open in your session. It does not fetch diagrams from other people, and it does not change the chat. The engine version is the `mermaid` dev dependency in `package.json`, shipped in `client.mermaid.js`.
